## Execution notes
- UI lives in `apps/helpdesk_agent/ui` (React + Vite + Tailwind + TypeScript). Follow `.claude/rules/ui.md`. `npm run build` output is served by FastAPI; CI builds it when `package.json` exists.
- Entra ID: MSAL with `VITE_AUTH_DEV_BYPASS=true` locally; roles are returned by `GET /me` from the API. The replay endpoint's 403/200 behaviour is proven by API tests, not by the UI.
- Grafana dashboard JSON goes in `infra/grafana/dashboards/uc1.json` and is provisioned by compose; the "dashboard renders" criterion is verified by `curl` against the Grafana API with `make stack-obs` running (UNMEASURED if the stack is not started).
