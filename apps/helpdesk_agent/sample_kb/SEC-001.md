# Report a suspicious email or phishing attempt

Do not click links, open attachments or reply with credentials when a message looks suspicious. Use the approved Report Phishing control in the company email application or contact the security team through the published channel. Preserve the message so investigators can examine its headers.
If you already clicked a link or supplied credentials, report that fact promptly and follow Security's instructions. Never send a password or one-time code to the helpdesk. A message claiming to be from management does not override identity checks or payment controls. The assistant cannot certify that a link is safe from its appearance alone. For a suspected compromised account, request a security incident ticket; do not attempt account recovery through an unknown website.
