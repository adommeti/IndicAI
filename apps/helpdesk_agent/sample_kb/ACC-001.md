# Request access to a shared folder or business application

Use the access-request form in the IT portal and identify the application or shared folder, the business purpose and the access level required. The resource owner and any required manager must approve the request before IT provisions access. Ask for the minimum permissions needed.
If access previously worked, note when it stopped and the exact error. A network connection problem is different from a permission denial, so mention whether other internal resources work. Do not use a colleague's account, copy restricted files into personal storage, or ask the assistant to override an approval. Track the request through its reference number. The helpdesk can explain the process but cannot grant access or guarantee that the owner will approve it.
