# Expired company password and account recovery

If your company password has expired, is forgotten, or your account is locked, create an IT support ticket. The helpdesk assistant cannot reset passwords, unlock accounts, change identity records, or promise that access has been restored. Provide the affected application, a non-secret description of the error, and an alternate approved contact channel.
IT verifies the employee's identity using its approved recovery procedure before taking action. Never send an existing password, authenticator code, recovery code, or security-question answer in a chat or ticket. Do not follow password-reset links supplied by an unknown caller. If a message claims urgency and asks for credentials, report it as suspected phishing. If the normal support portal is inaccessible, use the support contact published in the employee directory or ask your manager to raise the request through the approved channel.
