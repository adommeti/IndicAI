# Add an office printer and release a print job

Choose the approved office printer from the managed software or printer catalogue. Select the correct office and printer location, then print a non-confidential test page. If secure print is enabled, release the job at the device using the approved employee authentication method.
For a stuck job, check the printer display for paper or toner warnings and confirm that the selected printer is online. Cancel only your own queued job and retry once. Do not remove another employee's documents or bypass the secure-release mechanism. Report persistent errors to IT with the printer name, location and displayed message. Sensitive documents should be collected promptly and disposed of using the company's confidential-waste process.
