# Request and collect an employee ID badge

New employees request an ID badge through the onboarding portal. Complete the badge request with the required employee record and approved photograph, then submit it to the administration team. Admin confirms identity, office location and collection arrangements through the official request. Check the portal for updates before visiting the collection desk.
Bring the approved identity evidence specified in the collection message. Do not send identity-document scans in general chat, and do not borrow another employee's badge. Badge access may depend on completion of onboarding and local security checks; a submitted request is not permission to enter a restricted area. If your badge has been lost, report the loss promptly to Security so it can be disabled, then request replacement through the approved channel. The assistant cannot activate access or bypass identity checks.
